## Commands

### Update to the latest

```bash
hugo mod get -u github.com/CaiJimmy/hugo-theme-stack/v4
hugo mod tidy
```

### Update to specific version

```bash
hugo mod get github.com/CaiJimmy/hugo-theme-stack/v4@v4.1.0
```
